# R Programming: File Input and Output (I/O) Operations

Welcome to my repository! This project contains my practice scripts and notes focused on Reading and Writing Files in R Studio. Mastering data import and export operations is a fundamental step toward data analysis and data science.

---

## Topics Covered

### 1. Writing Data to a File
Practiced exporting the built-in gapminder dataset into a local directory as a pipe-separated (|) text file using the write.table() function.

### 2. Reading Data from a File
Learned how to load structured text files back into R Studio using read.table(), ensuring formatting remains intact by applying parameters like sep = '|' and header = TRUE.

### 3. Handling Excel Files with readxl
Installed and integrated the readxl library to seamlessly work with .xlsx files. Explored a dynamic approach to selecting files via the GUI using the file.choose() trick.
